Changing Geographic Prominence

How did country rankings change across AKON's dated records?
Each line traces a country's rank across decades.
Rank 1 is highest; lower positions indicate less representation.

Select a country to highlight its ranking trajectory.
Hover over points for record counts and collection shares.

Source: Austrian National Library, AKON Historical Postcards. Rankings use exactly dated records only. Country names follow present-day geographic boundaries.

The 1890s include only 1893–1899. The 1920s include only 1920–1925. These partial periods should not be compared as full decades.

Eight selected countries are displayed. Original ranks are preserved across all AKON countries. Ranking does not measure historical postcard production.
